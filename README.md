## ☕︎ Featured Project

### Hybrid RAG & Medical Knowledge Graph for Pharmacovigilance

Developed during my final-year internship at **SevenBlue SAS (France)**, this project focused on building an intelligent decision-support system for medical vigilance.

The system combines document retrieval, Large Language Models (LLMs), and a medical Knowledge Graph to improve the reliability and traceability of retrieved medical information.

**Key contributions:**
- Built a document ingestion and indexing pipeline for medical documents.
- Implemented hybrid retrieval combining dense vector search and BM25.
- Used BGE-M3 embeddings and Qdrant for vector search.
- Integrated a Knowledge Graph using RDF, SPARQL, and rdflib.
- Orchestrated the workflow with LangGraph.
- Developed REST APIs using FastAPI.
- Evaluated retrieval performance using a benchmark of 90 medical questions.

**Evaluation results:**
- Category@1: 100%
- Source@5: 81%
- Mean Reciprocal Rank (MRR): 0.617

**Technologies:** Python, BGE-M3, Qdrant, BM25, LangGraph, FastAPI, RDF, SPARQL, Amazon S3, Docker.
